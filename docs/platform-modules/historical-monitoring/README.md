## 1. Overview | Descripción general

### English

The AQUABOT MAX ECOSYSTEM Historical Monitoring module provides access to historical physicochemical water-quality records through an interactive interface.

The module brings together monitoring filters, variable selection, temporal visualization, descriptive statistics, and a historical records table.

It supports the exploration of water-quality observations across available monitoring periods and provides a basis for examining environmental changes over time.

### Español

El módulo Histórico de AQUABOT MAX ECOSYSTEM permite consultar registros históricos de calidad fisicoquímica del agua mediante una interfaz interactiva.

Integra filtros de monitoreo, selección de variables, visualización temporal, estadísticas descriptivas y una tabla de registros históricos.

Facilita la exploración de observaciones de calidad del agua en los periodos disponibles y proporciona una base para estudiar los cambios ambientales a lo largo del tiempo.

These controls allow users to examine available records according to the selected station, variable, and time period.

## 4. Temporal Visualization | Visualización temporal

### English

The module provides a temporal chart for reviewing the historical behavior of the selected physicochemical variable.

The visualization supports the examination of changes over time and complements the numerical records displayed in the historical table.

An empty or incomplete chart may reflect limited observations for the selected period rather than a measured value of zero.

### Español

El módulo dispone de una gráfica temporal para revisar el comportamiento histórico de la variable fisicoquímica seleccionada.

La visualización permite examinar cambios a lo largo del tiempo y complementa los registros numéricos presentados en la tabla histórica.

Una gráfica vacía o incompleta puede corresponder a observaciones insuficientes para el periodo seleccionado y no debe interpretarse como un valor medido igual a cero.

## 7. Data Availability and Quality | Disponibilidad y calidad de los datos

### English

Historical monitoring data must be interpreted according to their observation dates, monitoring sources, and availability.

The presence of a record in the platform does not, by itself, establish that it represents a laboratory-validated measurement.

If the system includes estimated, simulated, or reconstructed observations, these must be explicitly distinguished from direct sensor measurements.

Missing observations must not be represented as measured zeros.

### Español

Los datos históricos de monitoreo deben interpretarse considerando sus fechas de observación, fuentes de monitoreo y disponibilidad.

La presencia de un registro en la plataforma no establece, por sí sola, que se trate de una medición validada en laboratorio.

Cuando el sistema incluya observaciones estimadas, simuladas o reconstruidas, estas deben distinguirse explícitamente de las mediciones directas realizadas por sensores.

Las observaciones faltantes no deben representarse como valores medidos iguales a cero.

## 8. Scientific Relevance | Relevancia científica

### English

Historical monitoring records support the exploration of temporal variation in physicochemical water-quality parameters.

They provide useful information for comparing monitoring periods, identifying changes that warrant investigation, and complementing environmental observations obtained through other methods.

The results must be interpreted according to data provenance, methodological limitations, and the environmental context.

### Español

Los registros históricos de monitoreo permiten explorar la variación temporal de los parámetros fisicoquímicos de calidad del agua.

Proporcionan información útil para comparar periodos de monitoreo, identificar cambios que requieren investigación y complementar las observaciones ambientales obtenidas mediante otros métodos.

Los resultados deben interpretarse considerando la procedencia de los datos, las limitaciones metodológicas y el contexto ambiental.
